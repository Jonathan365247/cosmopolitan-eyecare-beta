# Start here

This is a clean, non-real-estate website beta. Read `AGENTS.md`, then `docs/beta-charter.md` before changing code or copy.

The goal is a thoughtful, fast, static-first site preview. Do not inherit names, copy, assets, integrations, legal language, data models, or assumptions from any other client project.

Before publishing a preview, run `npm run qa` and keep it protected and noindex.
